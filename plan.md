Название проекта: puzzl-games
Технология: Java, Spring Boot, Lombok, HTML


О текущем проекте:
 Это приложения представляет с собой игру, тест на знания на разные темы.
 Например: Как хорошо ты знаешь SQL? и тебе последовательно задается вопросы на эту тему с четырымя вариантами ответов где может быть только один правильный вариант  


Пример сайта на которую нужно ориентироваться при создании и оформлении фронт части приложения https://media.handlingbetter.ru/tests/
